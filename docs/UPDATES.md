# 遊戲更新處理

這個版本沒有預設排程、開機常駐檢查器或下載補丁的背景服務。

1. 每次遊戲更新後先不要按 F7；執行 `status`。如果是 `changed`，不要用舊候選或舊備份覆蓋它。
2. 正常關閉遊戲，保留整個 `.local/`。如果原遊戲檔案狀態不明，使用 Steam 驗證檔案，回到該版本原版，再依相容性流程準備新候選。
3. 新的 `prepare` 工作會使用獨立 job 資料夾，不刪掉舊備份。舊工具的既有安裝須先用原工具還原；若遊戲已更新而工具拒絕還原，不要強迫把舊原版寫回去。
4. 未知原版雜湊預設拒絕。人工檢查事件、欄位、Unity runtime 與原有流程後，才依 COMPATIBILITY.md 的進階方式測試。
5. 更新後需重新驗證計分、停止與前景隔離；需要開箱時另外驗證成功回呼。

若將來加入排程，建議只自動偵測雜湊與準備候選：遊戲執行中不終止、不覆寫；沒有更新就不通知，只有完成、失敗或需要操作時通知。新版本不一定能靠重新編譯修好。
